# Commands

### Manage your farmland
```
farm plant 1 watermelon     - plants watermelons on farmland #1
farm harvest all            - harvests all fully grown crops on all farmlands
farm fertilize 2 golden     - fertilizes farmland #2 using the golden fertilizer
farm water 1                - waters farmland #1
farm clear 2,3              - clears farmland #2 and #3 in order to plant new seeds
```

### Buy seeds, sell crops and upgrade farmland
```
farm buy potato 20          - buys 20 potato seeds
farm sell tomato 10         - sells 10 tomatoes
farm buy farmland           - buys additional farmland
farm upgrade 1              - upgrades the available space on farmland #1
```

### Information
```
farm show 1                 - shows information about farmland #1
farm show inventory seeds   - shows all seeds you have in your inventory
```

# Fertilizer

Fertilizers can be used to get various benefits

- ⏩ Accelerator -> Crops grow faster
- ✨ Golden -> Increases chance to become golden/perfect
- 🚿 Hydrating -> Reduces water consumption

<br/>

# Special Events

Every day, there's a chance for an event to occur. Events can have beneficial or harmful effects (or both) like harvesting crops will always result be golden/perfect or all crops are getting destroyed. They can last for several days

### Beneficial

- 🛸 Aliens -> All golden/perfect crops when harvesting
- 🌧️ Heavy Rain -> Waters everything
- 🌈 Rainbow -> Higher chance to get seeds back (or more seeds?)

### Mixed (beneficial and harmful)

- 🌩️ Lightning Storm -> Either destroys crops or upgrades them to golden/perfect
- 🌊 Tsunami -> destroys some crops but waters all farmlands
- ☄️ Comet -> Spreads random (special?) seeds to your empty farmlands (or replaces them?)

### Harmful

- 🌋 Volcano -> destroys all crops (all or some farmlands?)
- 🐙 Cthulhu (Curse) -> no golden/perfect when harvesting
- 🌵 Drought -> Farmland dries up 2x/3x as fast
